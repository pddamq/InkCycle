# 角色对话个性化

## 四步差异化
1. **语速**：性急者短句连发，谨慎者长句留白。给每个主要角色定一个"平均句长档位"。
2. **口头禅**：每人一个高频词或语气词（限一个，多则油腻），全篇保持。
3. **回避话题**：角色撒谎或紧张时会绕开关键词——让对话"答非所问"，比直说更有戏。
4. **信息差**：同一场对话，让每个角色只知道自己该知道的部分，警惕"全知对白"。

## 反面清单
- 所有角色都在替作者交代设定（说明腔）。
- 两人对话像问答机，一来一回超过 8 轮无动作插叙。
- 高情绪场景用陈述句平铺（愤怒应该让句子碎掉）。

## 修订口诀
改对白先念出声：拗口即删；谁的台词遮住名字猜不出人，就重写。
