# 悬疑伏笔技法

## 埋设军规
1. **三见原则**：关键伏笔至少出现三次——一次无感埋设、一次强化暗示、一次回收引爆。只出现一次的信息不叫伏笔，叫巧合。
2. **伪装**：伏笔首次出现必须裹在场景功能里（道具要有用途、闲话要有情绪），不能为埋而埋。
3. **克制度**：单章新埋伏笔不超过 2 个；每埋一个，检查台账是否登记。

## 回收军规
4. 回收要"提前一步"：读者刚想起伏笔时立刻兑现，比拖三章更有力。
5. 回收时点明埋设位置（"他这才明白当年铜牌上那道裂痕的来历"），给读者复盘快感。
6. 严禁"万能钥匙"式回收：一个伏笔只解一个谜，不许顺手解决所有矛盾。

## 审校检查点
- 本章新出现的道具/口头禅/异常细节，是否登记进伏笔台账？
- 台账里超过 5 章未推进的伏笔，本章是否有意识提及？
