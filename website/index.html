小说创作 Agent 是面向网文与长篇小说作者的本地 AI 写小说软件。 开书先访谈，导入成书能拆章、解析文风、画出剧情流程图；写作时由 Agent 起草、审校、修订，也可后台把整本书写完。

为长篇准备的功能，而不是一段聊天框

设定、角色、大纲、正文、伏笔与时间线在同一部作品里互相校验。模型负责写，软件负责记住全书，避免前后矛盾。

开书访谈

像编辑一样多轮追问主题、类型、主角、冲突、世界规则与雷点，汇编成可编辑的创作蓝图，再驱动设定、角色与大纲生成。

导入 · 拆章 · 仿写

上传或粘贴 txt / md，按第 X 章、第 X 卷自动拆章；抽样解析文风；抽出角色、伏笔与时间线。一键仿写只借节奏与文风，写原创句子。

Agent 审校循环

起草后对照世界观、人物卡、前文、伏笔台账打分；未达标则按意见修订，直到达到你设定的分数或轮数上限。

剧情流程图

卷泳道 + 章节卡片，显示状态、字数、出场人物与伏笔徽标；顺序流、回收弧与未回收节点可缩放、筛选并跳进编辑器。

整本自动创作

后台逐章走完起草—审校—修订。靠章节摘要维持连贯，进度持久化，中断后从未完成的章节继续，支持优雅停止。

Skills 与 MCP

安装 SKILL.md 写作技巧，按阶段注入提示词；连接 MCP 工具服务器，把外部检索或资料能力交给写作 Agent。

一条从空白到成书的路径

你可以访谈开书，也可以先导入一部参考作。两条路径最后都进入同一套书架、编辑器与整本创作。

1

收集意图

开书访谈覆盖定位、世界、人物、情节、文风与边界；或导入成书，自动得到章节与文风档案。

2

生成骨架

蓝图驱动世界观小节、角色卡与卷章大纲。导入路径则补摘要、伏笔与时间线，并生成流程图。

3

分章写作

按梗概起草，工具查询前文与设定；新伏笔与关键事件可写入台账。版本可预览、对比、回滚。

4

审校与完本

自动循环直到达标，或一键整本创作。导出 TXT / Markdown，范围可以是整本、单卷或单章。

把书导进来，看见结构，再按文风开写

适合研究对标作品、整理旧稿，或把喜欢的节奏变成自己的新故事。原文会单独保存并标记完成，不会被整本创作覆盖。

  1. 识别章节：第 X 章 / 第 X 卷 / Chapter N / 楔子 / 番外；没有标题则按篇幅切块。
  2. 文风档案：抽样开头、中段、结尾，归纳视角、节奏、句式、对话与用词。
  3. 结构入图：摘要、角色、伏笔与时间线写入数据库，流程图立刻可看。
  4. 一键仿写：新建作品，带入文风与章节骨架，不复制原句，启动整本创作。

写作时会查、也会记

起草与修订可调用角色、设定、前文搜索、未回收伏笔、时间线与邻章衔接；写完可登记伏笔、回收伏笔、记下时间线事件。审校阶段只读查询，先核实再下结论。

软件在你电脑上，模型由你指定

NovelAgent.exe 拷到任意目录就能跑。作品与 API 设置默认保存在本机 %APPDATA%\NovelAgent\，重装 exe 不会丢失；需要便携模式可设环境变量 NOVEL_AGENT_DATA。

  • 没有强制云端账号。作品不经过我们的服务器。
  • API Key 只存在本地。请求只发往你在设置里填写的 OpenAI 兼容地址。
  • 未配置 Key 时 AI 功能不可用。请先完成连接测试再开写。
  • 扩展可装可卸。Skills 支持文件夹、zip 与 GitHub；MCP 支持 stdio 与 HTTP。

常见问题

购买或部署前可以先看这四条。页面里的说明与软件实际行为一致。

小说创作 Agent 是在线 AI 写小说网站吗？

不是。它是 Windows 桌面软件，双击 NovelAgent.exe 即可使用。作品、设定与 API Key 保存在本机 SQLite，不会上传到我们的服务器。

需要什么模型才能写小说？

任意 OpenAI 兼容接口：OpenAI、DeepSeek、智谱 GLM、本地 Ollama 等。在设置中填写 Base URL 与 API Key 后即可创作。

导入别人的小说可以一键仿写吗？

可以导入 txt/md，自动拆章、解析文风并画出剧情流程图。一键仿写会新建作品，只带入文风、角色与章节骨架，不复制原文，并按原创纪律生成新稿。请自行确保你有权使用被导入的文本。

整本自动写完会中途丢掉进度吗？

不会。整本创作在后台逐章运行，进度写入本地数据库。离开页面、最小化或重启后，可以从未完成章节继续写。

获取小说创作 Agent

当前以可分发的 Windows 单文件为主。把 NovelAgent.exe 放到任意目录，双击启动，在「设置」里填入你的模型接口。

下载 NovelAgent.exe 阅读使用说明

若链接在托管环境中不可用，请使用你打包输出的 backend/dist/NovelAgent.exe。开发者可在仓库中用 pnpm 构建前端，再用打包脚本生成 EXE。
